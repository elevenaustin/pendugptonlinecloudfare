# PenduGPT™ — AI Website Masterclass Funnel & Training

Official high-converting interactive training funnel and enrollment platform for **PenduGPT™**.

## Features
- **Multi-Step Training Gate**: Step-by-step video progress tracking with anti-skip verification.
- **Lead Capture & WhatsApp Automation**: Automated registration syncing with n8n and WACRM.
- **Razorpay Integration**: Instant 1-click live checkout with automatic receipt confirmation.
- **Full Localization**: Punjabi and English multi-language interface.
- **Admin CRM Panel**: Live dashboard with lead filtering, order reconciliation, and real-time metrics.

## Development Setup

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```
